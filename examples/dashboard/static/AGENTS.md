# AGENTS.md · static

前端三个文件，无框架、无构建步骤。数据全部来自 `/api/*`，这里不做任何指标运算。

```
static/
├── index.html    页面骨架
├── app.js        状态与渲染
└── style.css     全部样式
```

## 设计策略

### 视觉方向

**实验室日志，不是仪表盘。** 目标是让人读实验记录，而不是看监控大屏。

- **左侧是账本**：按实验分组、可折叠、带日期边注。每个 run 显示 IC / 年化 / IR 三个摘要数，不点开就能横向扫。有图的 run 用实心方块 `◼`，无图的用空心圈 `○`。
- **右侧英雄区是一句话结论**，不是大数字。用衬线体写「5 日标签把 IC 抬高 45%，成本损耗几乎没有变化」，指标退到下面一排小格子。大数字 + 小标签是仪表盘的默认做法，刻意避开。
- **数字全部等宽**（IBM Plex Mono）。这是数据表的命门——不等宽的数字列无法纵向比较。

### 配色

冷灰底 + 单一深蓝灰强调色。

| 变量 | 值 | 用途 |
|---|---|---|
| `--ground` | `#F6F7F8` | 页面底色 |
| `--rail` | `#EDEFF1` | 左栏底色 |
| `--panel` | `#FFFFFF` | 选中项、图表容器 |
| `--ink` | `#0F1519` | 正文 |
| `--accent` | `#2B4A63` | 只在两处：选中态、激活页签 |
| `--pos` | `#1F6B4F` | 正向 delta |
| `--neg` | `#93312A` | 负向 delta、警告 |

**强调色只用两处。** 多一个颜色就掉一档质感。刻意避开了近黑配荧光、米色配陶土、卡片阴影这几类常见模板观感。

### 字体

| 角色 | 字体 | 理由 |
|---|---|---|
| 标题、结论 | Newsreader（衬线） | 期刊的编辑感，与数据区形成对比 |
| 正文 | IBM Plex Sans | 中文回落到 PingFang SC / 微软雅黑 |
| 数字、代码、标签 | IBM Plex Mono | 等宽是表格可读性的前提 |

### 交互

- 左栏选中项：左侧 2px 强调色竖条 + 白底，不用高亮块
- 图表区页签下划线指示；7 张图用 chip 切换，中文标签见 `SUB_LABEL`
- iframe 加载后测量 Plotly 内容高度再撑开，避免裁图
- 无图 run 显示空态说明和生成命令，不是破图

## 代码约定

**状态集中在一个 `state` 对象**：`runs` / `current` / `detail` / `chart` / `sub` / `query` / `closed`。改状态后显式调对应的 `render*()`，不做响应式绑定。

**渲染函数命名 `render{区域}`**：`renderRail` / `renderHeader` / `renderTabs` / `renderStrip` / `renderFrame` / `renderNotes`。每个负责一个区域，互不调用（`selectRun` 统一编排）。

**数值格式化函数在文件顶部**：`pct` / `pp` / `f4` / `f2` / `ddmm`。只做字符串格式化，不做计算——delta 和年化值由后端算好。

**不要在这里加指标运算。** 任何「这个数怎么来的」都应该回到 `metrics.py`。

## 已知不足

- Plotly 图内部字体和页面字体不一致。要统一得在 `report_graphs.py` 里给官方绘图函数传 `layout.font`，属于改官方图，暂未动。
- 没有前端路由，刷新总是回到第一个有图的 run。run 不多时够用；要分享链接就得加 hash 路由。
