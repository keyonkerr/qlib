# AGENTS.md · static

前端三个文件，无框架、无构建步骤。数据全部来自 `/api/*`，这里不做任何指标运算。

```
static/
├── index.html    页面骨架
├── app.js        术语词典 + 图版组件 + 八节渲染
└── style.css     全部样式
```

## 设计策略

### 视觉方向

**测量记录纸，不是仪表盘。** 页面把一次 run 当成标本，按「身份 → 实验设置 → 配置原文 → 信号 → 执行 → 结果 → 训练 → 官方图表 → 原始记录 → 出处」十节剖开。

- **底纹是坐标纸**：冷灰底 + 24px/96px 两级极淡网格。网格是「测量」的视觉母题，所有图版和表格压在同一张纸上。
- **只用两个重音色，各有职责**：普鲁士蓝 `#1E3A5F` 用于实测数据和当前选中；赭石 `#9C5B24` 用于第二条曲线和警告。
- **字体分工严格**：中文衬线（Noto Serif SC）只用于章节标题和结论；等宽（DM Mono）承载所有测量值；无衬线（Noto Sans SC）只写正文。
- **发丝线只有一个重量**：表格边框、图版边框、分隔线全部 1px 同级。层级靠留白和字号建立。

刻意避开的默认套路：卡片圆角 + 统一柔和阴影、暖米色底 + 陶土色、荧光绿配近黑、每个标题上方的小号全大写标签。

### 两个核心机制

**1. 术语词典（`GLOSSARY`）**

页面里 29 个带下划虚线的数字都可以点开说明卡，四层信息：**是什么 / 怎么算（精确到源码位置）/ 判读分档 / 常见误读**。这是自建平台相对 MLflow 界面的核心价值。

判读分档必须对照 qlib 源码的实际口径，不能拍脑袋。已核实的几条：

- 年化超额是 `日均 × 238` 的**算术累加**，不是复利（`qlib/contrib/evaluate.py::risk_analysis`）
- ICIR 记录的是日均值，年化要 `× √238`
- IC/Rank IC 是逐交易日 groupby 计算后取均值，不是整段算一个数（`qlib/contrib/eva/alpha.py::calc_ic`）
- `ffr/pa/pos` 在缺 `factor.day.bin` 时会同时退化（pa=0、pos=0、ffr=1）

新增术语时按同样的格式写进 `GLOSSARY`，键名用 qlib 的原始指标名（`glossaryFor` 会做前缀和后缀匹配）。

**2. 图版（`plate`）**

所有图——qlib 官方 Plotly 图和自算序列图——都收进同一个组件：**编号 / 标题 / 一句读法 / 数据 / 统计带**。不再有「页签切换」和「平铺直列」两套交互。

官方 Plotly 图**自动加载，不需要点击**。为避免首屏一次拉 14 张各约 3MB 的页面，`mountPending` 按文档顺序分批挂载（先 2 张，之后利用 `requestIdleCallback` 每批 4 张）。

不用 `IntersectionObserver`：页面在后台标签或隐藏窗格里可能永远不触发它，图会一直停在「图表载入中」。分批挂载不依赖可见性，任何情况下都能完成。

### 交互

- 左栏索引：**以 YAML 为维度**。实验 → 配置 → 该配置的多次运行。配置是一行，显示 IC、运行次数、多次运行时的 IC 极差；只有一个 run 时点配置行直接选中，多个 run 时展开后逐个切换
- **勾选对比**：每个 run 行左侧有方块勾选框（只跑一次的配置，勾选框挂在配置行上），勾中的显示槽位徽标 A/B/C/D，左下角粘性对比条可「开始对照 / 清空」。上限 4 个
- **对照页**：右侧整页换成「行是字段、列是 run」的八节表格。赭色 = 该值不同，靛蓝下划线 = 该行最优，虚线框「缺」= 该 run 没有此项。点 run 行、按 Esc 或「返回单 run 视图」均可退出，勾选保留
- 页面顶部有「同配置运行」区：列出该 YAML 的所有 run 与极差，并判断当前 run 是否偏离正常范围
- 左栏底部是页面目录，点击平滑跳转（目录只列当前可见那一页的章节）
- 术语卡一次只开一张，点击外部或按 Esc 关闭
- 图表 iframe 加载后测量 Plotly 内容高度再撑开，避免裁图

## 代码约定

**状态集中在一个 `state` 对象**：`configs` / `current` / `currentConfig` / `detail` / `query` / `closed` / `selected` / `compare` / `compareIds`。改状态后显式调对应的 `render*()`，不做响应式绑定。

**勾选状态就地更新，不重绘索引。** `syncPickBoxes` 改已有 checkbox 的 `checked` / `disabled` 和槽位徽标。若改成 `renderConfigs()`，被点击的那个 checkbox 会在 `change` 事件中途被销毁，浏览器随即把它回退成未勾选，并触发第二次 `change`——实测过，会「点一下勾上又自己取消」。

**两个容器不能同时持有同一个 `id`。** 解剖页和对照页都在 DOM 里，`renderOutline` 只给当前可见容器设 `act-*` id，并清掉另一个的，否则 `getElementById` 会命中隐藏的那个（实测过 `scrollIntoView` 定位到不可见章节）。

**对照页不做任何计算。** 差异、最优、缺失都由 `/api/compare` 标好（`same` / `best` / `always_diff`），这里只格式化。`fmtCell` 按后端给的 `kind` 选格式。

**索引以配置（YAML）为维度，不是 run。** 训练、验证、修改的对象都是 YAML，同一个 YAML 常常跑多次（`--repeat` 换 seed）。按 run 平铺会把这些重复运行混在一起，看不出「这次的不同是改了配置还是换了种子」。`/api/configs` 在后端就完成分组，前端只负责展示。

**渲染函数按节命名 `act{节}`**：`actIdentity` / `actSetting` / `actConfigSource` / `actSignal` / `actExecution` / `actOutcome` / `actTraining` / `actRecord` / `actProvenance`，由 `renderSpecimen` 统一编排。

**数值格式化函数在文件顶部**：`pct` / `num` / `signed` / `signPct` / `day`。只做字符串格式化，不做计算——delta 和年化值由后端算好。

**不要在这里加指标运算。** 任何「这个数怎么来的」都应该回到 `metrics.py` 或 `store.py`。

## 已知不足

- Plotly 图内部字体和页面字体不一致。要统一得在 `report_graphs.py` 里给官方绘图函数传 `layout.font`，属于改官方图，暂未动。
- 训练曲线共用纵轴时会压扁验证线（0.9636 对 0.9945 是数据真相）。页面用「末轮差距」「验证最低」两个数字补足肉眼看不到的部分。
- 没有前端路由，刷新总是回到第一个有图的 run。要分享链接就得加 hash 路由。
