# 03 数据篇：数据层与接入自己的数据

数据层是 Qlib 的底座。本文讲清楚：**数据存成什么样 → 怎么读 → 怎么加工 → 怎么换成你自己的数据**。

---

## 一、数据在 Qlib 里怎么流转

```
① 下载/转换 → .bin 格式（磁盘上只存 OHLCV 等基础数据）
        ↓
② 表达式引擎 → 算出基础特征（如 Ref($close,60)/$close）
        ↓
③ Processor → 复杂加工（标准化、填缺失值、去极值）
        ↓
④ Dataset → 按训练/验证/测试切分，喂给模型
```

**关键区分**：

- **② 表达式引擎的算子（Operator）**：单行公式，如 `Mean($close, 5)`
- **③ Processor**：需要「学习参数」或跨行统计的加工，如 z-score（要先算出 mean/std）

两者不能互相替代——z-score 这种需要先 `fit` 再 `transform` 的逻辑，表达式引擎做不了。

---

## 二、数据格式：`.bin` 文件

Qlib 用自定义的二进制格式存储金融数据，后缀 `.bin`。设计目标是**高性能科学计算**（内存映射 + 列式存储）。

### 下载现成数据

```bash
# A 股日频
.venv/bin/python scripts/get_data.py qlib_data --target_dir ~/.qlib/qlib_data/cn_data --region cn

# A 股 1 分钟
.venv/bin/python scripts/get_data.py qlib_data --target_dir ~/.qlib/qlib_data/qlib_cn_1min --region cn --interval 1min

# 美股日频
.venv/bin/python scripts/get_data.py qlib_data --target_dir ~/.qlib/qlib_data/us_data --region us
```

> ⚠️ 这些数据来自 **Yahoo Finance**，质量有限。qlib 下载时会明确警告：
>
> > The data for the example is collected from Yahoo Finance. Please be aware that the quality of the data might not be perfect.
>
> 生产环境建议用 tushare / wind / 聚宽 等国内数据源，通过 `scripts/data_collector/` 接入。

### 目录结构

```
~/.qlib/qlib_data/cn_data/
├── calendars/
│   └── day.txt              ← 交易日历，每行一个日期
├── instruments/
│   ├── all.txt              ← 全市场股票及起止日期
│   ├── csi300.txt
│   ├── csi500.txt
│   └── csi100.txt
└── features/
    ├── sh600000/
    │   ├── open.day.bin
    │   ├── high.day.bin
    │   ├── low.day.bin
    │   ├── close.day.bin
    │   ├── volume.day.bin
    │   └── factor.day.bin   ← 复权因子（示例数据里可能缺失）
    └── ...
```

**本次下载的数据**：510MB、3875 只股票。

### ⚠️ 价格是「复权后」的，不是真实成交价

Qlib 的 `$close` 是**复权价**，每只股票以**上市首日归一化为 1**。

```
$close / $factor = 原始成交价
```

不同数据源复权方式不同，所以同样一只股票的价格在不同来源里可能对不上。这是正常现象。

## 三、数据 API

### 初始化

```python
import qlib
from qlib.constant import REG_CN

qlib.init(provider_uri="~/.qlib/qlib_data/cn_data", region=REG_CN)
```

`region` 决定了交易规则：

| Region | 交易单位 | 涨跌停阈值 |
|---|---|---|
| China（`REG_CN`） | 100 股 | 0.099 |
| US（`REG_US`） | 1 股 | 无 |

### 取原始数据：`D.features()`

```python
from qlib.data import D

# 单字段
df = D.features(["SH600000"], ["$close"], start_time="2020-01-01", end_time="2020-03-01")

# 多字段 + 表达式
df = D.features(
    ["SH600000", "SH600004"],
    ["$close", "$volume", "Ref($close, 5)/$close", "Mean($close, 20)"],
    start_time="2020-01-01", end_time="2020-03-01",
    freq="day",
)
```

返回 MultiIndex DataFrame：

```
                        $close   $volume   Ref($close,5)/$close   Mean($close,20)
instrument  datetime
SH600000    2020-01-02   3.12    120000            1.0234              3.08
```

### 常用算子

| 类别 | 算子 |
|---|---|
| 时间引用 | `Ref(x, n)` 前 n 期、`Ref(x, -n)` 后 n 期 |
| 统计 | `Mean` `Std` `Sum` `Max` `Min` `Rank` `Quantile` |
| 趋势 | `Slope` `Rsquare` `Resi` |
| 相关性 | `Corr(x, y, n)` |
| 逻辑 | `Greater` `Less` `If` |
| 数学 | `Log` `Abs` `Sign` `Power` |

完整列表见 [qlib/data/ops.py](../qlib/data/ops.py)。

### 取股票池

```python
# csi300 的成分股
instruments = D.instruments("csi300")
# 或直接读文件
codes = D.list_instruments(D.instruments("csi300"), as_list=True)
```

### 过滤股票：Filter

```yaml
filter: &filter
    filter_type: ExpressionDFilter
    rule_expression: "Ref($close, -2) / Ref($close, -1) > 1"   # 明天比后天涨
    filter_start_time: 2010-01-01
    filter_end_time: 2010-01-07
    keep: False

data_handler_config:
    filter_pipe: [*filter]
```

三种常见过滤：

| 类型 | 表达式示例 |
|---|---|
| 基础特征 | `$close/$open > 5` |
| 截面特征 | `$rank($close) < 10`（价格排名前 10） |
| 时序特征 | `Ref($close, 3) > 100` |

## 四、Data Loader：数据从哪来

`DataLoader` 负责**把原始数据读进来**，有两种实现。

### `QlibDataLoader`（默认）

从 Qlib 的 `.bin` 数据源读，配合表达式引擎。

```python
data_loader = {
    "class": "QlibDataLoader",
    "kwargs": {
        "config": {
            "feature": (["$close", "Mean($close,5)"], ["CLOSE", "MA5"]),
            "label":   (["Ref($close,-2)/Ref($close,-1)-1"], ["LABEL0"]),
        },
        "freq": "day",
    },
}
```

### `StaticDataLoader`（接自己的数据）

直接加载现成的 DataFrame 或 parquet，**绕过表达式引擎**。

```python
from qlib.data.dataset.loader import StaticDataLoader

loader = StaticDataLoader(config={
    "feature": my_feature_df,   # MultiIndex = (datetime, instrument)
    "label":   my_label_df,
})
```

`config` 支持 `dict[str, DataFrame]` 或文件路径（[qlib/data/dataset/loader.py:274](../qlib/data/dataset/loader.py)）。

## 五、Data Handler：数据怎么加工

`DataHandler` 是「数据 + 加工流程」的封装，最常用的是 `DataHandlerLP`（LP = Learnable Processors）。

### 核心思想：可学习的 Processor

普通函数是固定的（如 `log(x)`），但 **z-score 需要先知道 mean/std**：

```python
class ZScoreNorm:
    def fit(self, df):
        self.mean = df.mean()   # 学参数
        self.std  = df.std()

    def __call__(self, df):
        return (df - self.mean) / self.std   # 用学到的参数
```

这样**训练时学参数，实盘时用同样的参数处理新数据**——这是量化系统能上生产的关键。

### 两条数据流

`DataHandlerLP` 内部维护两套数据（[qlib/data/dataset/handler.py:570](../qlib/data/dataset/handler.py)）：

```
原始数据
   ↓
shared_processors（两者共用）
   ├─→ infer_processors → _infer（DK_I，推理/预测用）
   └─→ learn_processors → _learn（DK_L，训练用）
```

**为什么分开**：

- **训练（learn）** 需要 `CSZScoreNorm` 做截面标准化，让同一天的股票可比
- **推理（infer）** 面对的是单点数据，只能做时序标准化

源码注释：

> `(self._data)-[shared_processors]-(_shared_df)-[infer_processors]-(_infer_df)-[learn_processors]-(_learn_df)`

### 常用 Processor

| Processor | 作用 |
|---|---|
| `DropnaLabel` | 丢掉标签缺失的行 |
| `DropnaProcessor` | 丢掉指定列缺失的行 |
| `ProcessInf` | 无穷值 → 该列均值 |
| `ZScoreNorm` | 时序 z-score（按列，跨时间） |
| `CSZScoreNorm` | 截面 z-score（同一天，跨股票） |
| `CSRankNorm` | 截面 rank 归一化（比 z-score 抗异常值） |
| `RobustZScoreNorm` | 用中位数/MAD 代替均值/标准差 |
| `Fillna` | 缺失填 0（或指定值） |
| `MinMaxNorm` | 缩放到 [0,1] |
| `FilterCol` | 删除指定列 |

完整列表见 [qlib/data/dataset/processor.py](../qlib/data/dataset/processor.py)。

### ⚠️ Alpha158 和 Alpha360 的默认值不一样

```python
_DEFAULT_INFER_PROCESSORS = [          # ← Alpha360 用
    {"class": "ProcessInf"},
    {"class": "ZScoreNorm"},
    {"class": "Fillna"},
]
_DEFAULT_LEARN_PROCESSORS = [          # ← 两者都用
    {"class": "DropnaLabel"},
    {"class": "CSZScoreNorm", "kwargs": {"fields_group": "label"}},
]

class Alpha158(...):
    def __init__(..., infer_processors=[], ...):   # ← 默认空列表！
```

| 数据集 | infer_processors 默认 |
|---|---|
| `Alpha360` | ProcessInf + ZScoreNorm + Fillna |
| `Alpha158` | **`[]`（什么都不做）** |

**所以跑 Alpha158 时实际只有 2 个 learn processor 生效**——这也是运行日志里只打印两行的原因。

详见 [模型篇](05-模型篇.md#第-4-层数据加工processor)。

## 六、Dataset：切分与取数

`Dataset` 从 Handler 里按时间段取数据。

```python
from qlib.data.dataset import DatasetH

dataset = DatasetH(handler=handler, segments={
    "train": ("2008-01-01", "2014-12-31"),
    "valid": ("2015-01-01", "2016-12-31"),
    "test":  ("2017-01-01", "2020-08-01"),
})
```

### 两种 Dataset

| 类 | 适用 | 输出形状 |
|---|---|---|
| `DatasetH` | 表格数据（树模型、线性模型） | `(样本, 特征)` |
| `TSDatasetH` | 时间序列（LSTM、Transformer） | `(样本, 时间步, 特征)` |

`TSDatasetH` 会自动往前多取 `step_len` 天，保证每个样本有完整窗口（[qlib/data/dataset/__init__.py:642](../qlib/data/dataset/__init__.py)）：

```python
class TSDatasetH(DatasetH):
    DEFAULT_STEP_LEN = 30
    def _extend_slice(self, slc, cal, step_len):
        pad_start_idx = max(0, start_idx - step_len)
        return slice(cal[pad_start_idx], slc.stop)
```

### 取数

```python
# 训练数据（learn 流）
df_train = dataset.prepare("train", col_set=["feature", "label"], data_key=DataHandlerLP.DK_L)

# 测试数据（infer 流）
df_test = dataset.prepare("test", col_set="feature", data_key=DataHandlerLP.DK_I)
```

**注意 `data_key`**：训练用 `DK_L`，推理用 `DK_I`。

## 七、怎么接入自己的数据（四个层次）

### 层次 1：替换行情数据（OHLCV）

**场景**：你有自己的数据库/CSV，想替换掉 `~/.qlib/qlib_data/cn_data`。

**做法**：转成 `.bin` 格式。

```bash
.venv/bin/python scripts/dump_bin.py dump_all \
    --data_path ~/my_data \
    --qlib_dir ~/.qlib/qlib_data/my_data \
    --include_fields open,close,high,low,volume,factor \
    --file_suffix .csv \
    --date_field_name date \
    --symbol_field_name symbol
```

**CSV 格式要求**：

```
symbol,date,open,close,high,low,volume,factor
SH600000,2020-11-01,120,121,123,119,12300000,1.0
SH600000,2020-11-02,121,123,124,120,11200000,1.0
```

或者**每只股票一个文件**：`SH600000.csv`（文件名即代码）。

**字段含义**：

| 字段 | 含义 |
|---|---|
| `open` / `high` / `low` / `close` | **复权后**的价格 |
| `volume` | 成交量 |
| `factor` | 复权因子，`factor = 复权价 / 原始价` |

**停牌处理**：`open/close/high/low/volume/money/factor` 会被设为 NaN。

**然后改 YAML**：

```yaml
qlib_init:
    provider_uri: "~/.qlib/qlib_data/my_data"
    region: cn
```

**这样 Alpha158 的 158 个因子会从你的数据里重新算出来。**

### 层次 2：用自己的因子表

**场景**：你已经有算好的因子（pandas / 别处导出 / 买的因子库）。

```python
import pandas as pd
from qlib.data.dataset.loader import StaticDataLoader
from qlib.data.dataset.handler import DataHandlerLP

df = pd.read_parquet("my_factors.parquet")
#                     feature                    label
# datetime   instrument   alpha1  alpha2  ...    LABEL0
# 2020-01-02 SH600000      0.23   -1.05  ...     0.0042

loader = StaticDataLoader(config={"feature": my_feature_df, "label": my_label_df})
handler = DataHandlerLP(instruments="csi300",
                        start_time="2015-01-01", end_time="2020-08-01",
                        data_loader=loader)
```

**这绕过了整个表达式引擎，你给什么它就用什么。**

### 层次 3：在 Alpha158 基础上加因子

```python
from qlib.contrib.data.handler import Alpha158
from qlib.contrib.data.loader import Alpha158DL

class MyAlpha(Alpha158):
    def get_feature_config(self):
        base_fields, base_names = Alpha158DL.get_feature_config()

        my_fields = [
            "Corr($close, Log($volume+1), 20)",    # 20日价量相关
            "Std($close, 10)/Mean($close, 10)",     # 10日变异系数
            "Ref($volume, 1)/($volume+1e-12)",      # 昨日量比
        ]
        my_names = ["MY_CORR20", "MY_CV10", "MY_VOLRATIO"]

        return base_fields + my_fields, base_names + my_names
```

YAML 里：

```yaml
handler:
    class: MyAlpha
    module_path: my_project.handlers    # 你放这个类的模块路径
    kwargs: *data_handler_config
```

### 层次 4：自定义标签

```python
class MyAlpha(Alpha158):
    def get_label_config(self):
        # 5 日后收益
        return ["Ref($close, -6)/Ref($close, -1) - 1"], ["LABEL0"]

        # 或二分类：未来5天涨超2% 记 1
        # return ["Greater(Ref($close,-6)/Ref($close,-1)-1, 0.02)"], ["LABEL0"]
```

## 八、数据健康检查

Qlib 提供脚本检查数据质量：

```bash
# 日频
.venv/bin/python scripts/check_data_health.py check_data --qlib_dir ~/.qlib/qlib_data/cn_data

# 1 分钟
.venv/bin/python scripts/check_data_health.py check_data --qlib_dir ~/.qlib/qlib_data/cn_data_1min --freq 1min
```

检查四项：

1. DataFrame 里有没有缺失数据
2. OHLCV 有没有超过阈值的大跳变
3. 必需列（OHLCV）是否齐全
4. `factor` 列是否缺失

可调参数：

| 参数 | 含义 |
|---|---|
| `missing_data_num` | 允许缺失的最大数量 |
| `large_step_threshold_price` | 允许的最大价格变化 |
| `large_step_threshold_volume` | 允许的最大成交量变化 |

## 十、缓存结构

Qlib 有两级缓存：

| 层级 | 位置 | 作用 |
|---|---|---|
| **内存缓存 H** | 进程内 | 缓存最近访问的字段，`qlib.init()` 时清空 |
| **磁盘缓存** | `~/.qlib/qlib_data/*/features/` | 就是 `.bin` 文件本身 |

表达式计算的结果也会缓存，所以第二次读同一个表达式会快很多。
