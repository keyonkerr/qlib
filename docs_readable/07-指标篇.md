## 第一块：信号评估 —— IC 家族

```
{'IC': 0.0468, 'ICIR': 0.3816, 'Rank IC': 0.0490, 'Rank ICIR': 0.4068}
```

这四个数字回答同一个问题：**模型预测的分数，和股票未来真实的涨跌，到底有多相关？**

它们全部由 `SigAnaRecord` 计算，源码在 [qlib/contrib/eva/alpha.py:160](../qlib/contrib/eva/alpha.py)。

```python
def calc_ic(pred, label, date_col="datetime"):
    df = pd.DataFrame({"pred": pred, "label": label})
    ic  = df.groupby(date_col).apply(lambda d: d["pred"].corr(d["label"]))
    ric = df.groupby(date_col).apply(lambda d: d["pred"].corr(d["label"], method="spearman"))
    return ic, ric
```

注意 `groupby(date_col)`——**不是整段算一个数，而是每个交易日单独算一个**。回测期 871 天，就得到 871 个 IC 值，然后取平均。

### IC（Information Coefficient，信息系数）

**怎么算**：每一天，把当日所有股票的「模型预测分数」和「真实收益（label）」做一次 **Pearson 相关系数**，再把 871 天的结果取算术平均。

**含义**：0 = 预测和真实收益毫无关系；1 = 完全同向；-1 = 完全反向。

**本次结果分析**：

| 统计量 | 值 | 说明 |
|---|---|---|
| 均值 | 0.0468 | 本次主指标 |
| 标准差 | 0.1227 | **波动是均值的 2.6 倍** |
| 中位数 | 0.0465 | 与均值几乎一致，分布对称 |
| 5% 分位 | -0.1454 | 最差的 5% 日子 |
| 95% 分位 | 0.2467 | 最好的 5% 日子 |
| 最大值 | 0.4069 | |
| 最小值 | -0.3720 | |
| 为正的天数 | **568 / 868 = 65.4%** | 约 2/3 的日子方向正确 |

**关键认知**：单日 IC 波动（±0.12）远大于均值（0.047）。这是金融数据的常态——**任何一天的 IC 都说明不了问题，必须看长期均值**。

我另外验证了极端值的影响：`|IC| > 0.3` 的日子只有 23 天（2.6%），剔除后均值变成 0.0417。说明这个 0.047 **不是靠少数极端行情撑起来的**，比较扎实。

**好坏判断（日频 A 股）**：

| IC | 评价 |
|---|---|
| < 0.02 | 基本没用 |
| 0.02 ~ 0.03 | 勉强，需配合其他信号 |
| **0.03 ~ 0.05** | **可用** ← 本次 0.0468 在这里 |
| 0.05 ~ 0.10 | 好 |
| > 0.10 | **可疑**，大概率有前视偏差（用了未来信息） |

### ICIR（IC 信息比率）

**怎么算**：

```python
ICIR = IC 均值 / IC 标准差 = 0.046805 / 0.122668 = 0.381558
```

（可以手算验证，结果与控制台打印的 0.3816 完全一致。）

**含义**：衡量 IC 的**稳定性**，相当于「IC 的夏普比率」。同样是 IC=0.05，标准差 0.05 的策略（ICIR=1.0）远比标准差 0.15 的策略（ICIR=0.33）可靠——前者每天都能稳定赚钱，后者靠少数好日子撑着。

**好坏判断（⚠️ 先确认口径）**：

ICIR 有两套口径，差一个 `√N`，混用会得出完全相反的结论：

```
未年化 ICIR = mean(IC) / std(IC)              = 0.3816   ← qlib 打印的是这个
年化   ICIR = 未年化 ICIR × √238              = 5.89     ← 多数券商研报/参数表用这个
```

| 未年化 ICIR | 年化 ICIR（×√238） | 评价 |
|---|---|---|
| < 0.10 | < 1.5 | 不稳定，实盘容易失效 |
| 0.10 ~ 0.15 | 1.5 ~ 2.3 | 较弱 |
| 0.15 ~ 0.25 | 2.3 ~ 3.9 | 可用 |
| **0.25 ~ 0.40** | **3.9 ~ 6.2** | **良好** ← 本次 0.3816 在这里 |
| > 0.40 | > 6.2 | 优秀，但要警惕过拟合 |

> **「ICIR > 0.4 才是有效因子」这类流传的说法，绝大多数指年化口径。** 若误套到未年化值上，门槛会低到荒谬——qlib 官方 CSI300/Alpha158 基准里，26 个模型只有 DoubleEnsemble 达到未年化 0.4223。判断时务必先问「这是年化还是未年化」。

**最可靠的判断锚点不是区间表，而是官方基准对比**（见 [模型篇](05-模型篇.md)）：

| 模型 | IC | ICIR（未年化） |
|---|---|---|
| DoubleEnsemble | 0.0521 | 0.4223 |
| **本次运行** | **0.0468** | **0.3816** |
| XGBoost | 0.0498 | 0.3779 |
| LightGBM | 0.0448 | 0.3660 |
| CatBoost | 0.0481 | 0.3366 |

本次结果落在官方 LightGBM 的正常波动范围内，属**符合预期**。

### Rank IC（RIC）

**怎么算**：把当日的预测值和真实收益都**替换成排名**，再算相关系数（即 Spearman 秩相关）。

**为什么要多算一个**：Pearson 相关对异常值敏感。某只股票当天涨了 20%，会大幅影响普通 IC，但它在你 50 只持仓里可能只占 2%。Rank IC 只看「排名的顺序对不对」，天然抑制异常值。

**本次 0.0490 略高于普通 IC 0.0468**，说明：

- 极端涨跌股对线性相关系数造成了一点拖累
- 模型在**排序能力**上比线性拟合稍强
- 而这正是 `TopkDropoutStrategy` 这类**按排名选股**的策略真正需要的能力

### Rank ICIR

`0.0490 / Rank IC 标准差 = 0.4068`，含义同 ICIR，只是换成排名视角。比普通 ICIR 更高，同样是好消息。

三组的含义：

|---|---|---|
| benchmark | 沪深300 本身的日收益 | 什么都不做能拿到多少 |
| excess_return_without_cost | 策略收益 − 基准 | **纯选股能力**（不计交易成本） |

### mean（均值）

就是**日收益的算术平均**，没有年化。

```python
mean = r.mean()
```

本次「不计成本超额」的 mean = **0.000530**，即**平均每天比沪深300 多赚 0.053%**。

### std（标准差 / 波动率）

```python
std = r.std(ddof=1)
```

本次「不计成本超额」的 std = **0.005718**，即**日超额收益的波动是 0.572%**。

注意这是**超额**的波动，不是绝对波动。策略绝对收益的波动和基准差不多（都在 1.2% 左右），相减之后共同的市场波动被对冲掉，剩下来 0.57% 才是纯选股带来的波动。

**所以「日均赚 0.053%，日波动 0.572%」意味着：波动是收益的 10 倍以上。** 单看某一天、某一个月，完全看不出策略好坏，必须看长期。

### annualized_return（年化收益）

```python
annualized_return = mean * N     # N = 238
```

本次 `0.000530 × 238 = 0.1261` ✓

三组分别是 11.36%（基准）、12.60%（超额不计成本）、8.07%（超额计成本）。

> **⚠️ 重要细节：qlib 用的年化因子是 238，不是业界常用的 252。**
>
> 源码见 [qlib/contrib/evaluate.py:47-53](../qlib/contrib/evaluate.py)：
>
> ```python
> _freq_scaler = {
>     Freq.NORM_FREQ_MINUTE: 240 * 238,
>     Freq.NORM_FREQ_DAY: 238,      # ← 这里
>     Freq.NORM_FREQ_WEEK: 50,
>     Freq.NORM_FREQ_MONTH: 12,
> }
> ```
>
> A 股实际每年约 242 个交易日。如果改用 252 重新计算，本次三组年化会变成 12.02% / 13.34% / 8.54%（IR 变成 0.616 / 1.470 / 0.941）。
> **和论文、其他平台对比数字时，一定要先统一年化口径。**

### information_ratio（信息比率，IR）

中文叫**信息比率**，是金融界最看重的综合评价指标。

```python
information_ratio = mean / std * np.sqrt(N)
```

即「收益的信噪比」——**承担一份波动，能换来多少收益**。

**为什么重要**：收益可以靠加杠杆放大，但 IR 衡量的是策略本身的**质量**，加杠杆不会改变 IR。所以：

- 年化 20%、波动 40% → IR ≈ 0.8（平庸）
- 年化 10%、波动 5% → IR ≈ 2.0（优秀）

**本次三行**：

| 组 | IR | 含义 |
|---|---|---|
| benchmark | 0.5987 | 市场本身的性价比 |
| excess without cost | **1.4286** | 模型的纯选股能力，**很强** |
| excess with cost | 0.9145 | 实盘能拿到的 |

**判断标准**：

| IR | 评价 |
|---|---|
| < 0.5 | 一般 |
| 0.5 ~ 1.0 | 不错 |
| **1.0 ~ 2.0** | **优秀** |
| > 2.0 | 罕见，需警惕数据问题 |

**关键观察**：纯选股 IR 是 1.43，实盘 IR 掉到 0.91，**损失约 36%**。这个落差全部来自交易成本——所以调参时**换手率比模型精度更重要**。

### max_drawdown（最大回撤）

```python
max_drawdown = (r.cumsum() - r.cumsum().cummax()).min()
```

净值曲线从历史最高点回落的最大幅度。本次：基准 -37.05%（2018 年熊市），超额 -7.23%（不计成本）和 -8.61%（计成本）。

**判断**：回撤越接近 0 越好。但要注意它衡量的是「最坏情况」，-10% 以内对股票策略已属可控。

### 一个必须知道的实现细节：加法累积

qlib 的年化收益是 `mean × N`（**加法累积**），而不是复利。源码注释明确说这是**刻意的设计**：

> Qlib tries to cumulate returns by summation instead of production to avoid the cumulated curve being skewed exponentially.
> （用连乘的话，累计曲线会呈指数歪斜，掩盖真实表现，所以 qlib 统一用简单相加。）

所以 qlib 的数字会比「真实复利」略保守，跨平台对比时同样要注意。

## 第三块：执行质量 —— ffr / pa / pos

```
'The following are analysis results of indicators(1day).'
     value
ffr    1.0
pa     0.0
pos    0.0
```

这三个来自**回测引擎的订单执行层面**，衡量「下单到底下成了什么样子」，和策略盈亏是两个维度。源码在 [qlib/backtest/report.py:608](../qlib/backtest/report.py)：

```python
fulfill_rate    = self._cal_trade_fulfill_rate(...)      # ffr
price_advantage = self._cal_trade_price_advantage(...)   # pa
positive_rate   = self._cal_trade_positive_rate()        # pos
self.trade_indicator["ffr"] = fulfill_rate
self.trade_indicator["pa"]  = price_advantage
self.trade_indicator["pos"] = positive_rate
```

### ffr —— 订单成交率（Fulfill Rate）

```python
def func(deal_amount, amount):
    tmp_deal_amount = deal_amount.reindex(amount.index, 0).replace({np.nan: 0})
    return tmp_deal_amount / amount      # 实际成交 / 想成交
```

**本次 1.0 = 100% 成交，一单没被拒。**

**作用**：反映**策略收益的可实现性**。如果 ffr 只有 0.8，说明想买 100 手只买到 80 手，没买到的往往是涨得最凶或跌停买不进的票——实盘收益会明显低于回测。

**为什么这里是 1.0**：csi300 大盘股流动性充足、单笔订单远小于市场容量、2017-2020 无系统性股灾。

**什么时候会掉**：策略换成小盘股、加大仓位、或遇到连续涨跌停行情。

### pa —— 成交价优势（Price Advantage）

```python
def func(trade_dir, trade_price, base_price):
    sign = 1 - trade_dir * 2         # BUY=1 → sign=-1；SELL=0 → sign=+1
    return sign * (trade_price / base_price - 1)
```

（`BUY = 1`、`SELL = 0`，见 [qlib/backtest/decision.py:30](../qlib/backtest/decision.py)。`base_price` 是当日基准均价。）

**符号设计很巧妙**，无论买卖，**pa 为正都是好事**：

- 买入时 `sign = -1`，成交价**低于**均价 → pa 为正（买便宜了）
- 卖出时 `sign = +1`，成交价**高于**均价 → pa 为正（卖贵了）

**本次 0.0 = 成交价与当日基准均价持平**，既没占到便宜也没吃亏。

**作用**：衡量**执行质量**，是高频策略和算法拆单（TWAP/VWAP）最关心的指标。同样的买单拆得好，能比均价便宜 0.1%，一年下来能多出几个点的收益。对日频 TopkDropout 这种「按收盘价一次性撮合」的策略，pa 天然接近 0。

**注意**：pa 的单位是**价格偏离比例**（0.001 = 0.1%），不是收益率，不能与 mean/std 直接比较。

### pos —— 正优势成交占比（Positive Rate）

```python
def func(pa):
    return (pa > 0).sum() / pa.count()    # pa 为正的笔数 / 总笔数
```

**注意**：它算的是 `pa > 0` 的占比，**不是「盈利交易占比」**。名字里的 `pos` 容易误导，它是「有价格优势的成交占多少比例」。

**本次 0.0**：没有一笔成交获得价格优势——与 pa=0.0 完全自洽（全部持平，自然没有正的）。

**作用**：和 pa 配合看。若 pa=0.001 但 pos=0.2，说明少数大额成交占到便宜、普惠性差；若 pa=0.001 且 pos=0.8，说明稳定占优。

### 三者速查

| 指标 | 中文 | 回答什么问题 | 良好取值 |
|---|---|---|---|
| ffr | 成交率 | 想买的买到了吗？ | → 1.0 |
| pa | 成交价优势 | 买得便宜/卖得高吗？ | > 0，越大越好 |
| pos | 正优势占比 | 有多少笔占到便宜？ | → 1.0 |

**日频 + 大盘股 + 按收盘价撮合**的回测里，`1.0 / 0.0 / 0.0` 是完全正常的结果，说明引擎没有撮合异常。等你跑 `examples/highfreq/` 里的高频示例，这几个数字才会有明显变化，那时才真正有分析价值。

## 信号评估方法论：怎么判断一个信号「好不好」

前面讲的是每个指标怎么算。这一节讲**判断方式本身**——比数字更重要的是锚点的选择。

### 一、不要依赖流传的「经验区间表」

网上和研报里流传着大量这样的表：

> IC > 0.05 优秀，0.03~0.05 有效，0.02~0.03 较弱
> ICIR > 0.4 是有效因子，> 1 是顶级因子

这些表有几个问题：

1. **口径不明**：ICIR 是年化还是未年化？差一个 `√N`（约 15 倍），结论完全相反
2. **前提不明**：日频/月频、A股/美股、csi300/全市场，标准差异巨大
3. **用途不明**：是「单因子筛选」还是「多因子组合中的一员」？

这类区间表只能当作**入门粗筛**，不能作为精确判断依据。

### 二、三个可靠的判断锚点

#### 锚点 1：官方基准对比（最可靠）

用同样的数据、同样的回测配置跑官方基准，看你的结果落在什么位置。

qlib 官方 CSI300 / Alpha158 基准（20 次运行均值）：

| 模型 | IC | ICIR（未年化） | 年化收益 | IR |
|---|---|---|---|---|
| DoubleEnsemble | 0.0521 | 0.4223 | 11.58% | 1.3432 |
| XGBoost | 0.0498 | 0.3779 | 7.80% | 0.9070 |
| CatBoost | 0.0481 | 0.3366 | 7.65% | 0.8032 |
| **本次运行** | **0.0468** | **0.3816** | **12.60%** | **1.4286** |
| LightGBM | 0.0448 | 0.3660 | 9.01% | 1.0164 |

**结论**：本次结果落在 LightGBM 官方 20 次运行的正常波动区间内，**符合预期，无需担心**。

> 注意本次年化 12.60% 和 IR 1.4286 高于官方表里的 LightGBM（9.01% / 1.0164）。原因有两个：①本次是「不计成本」口径，官方表是「计成本」；②官方是 252 天年化，qlib 用 238 天。**对比前必须先对齐口径。**

#### 锚点 2：统计显著性（t 检验）

IC 均值显著大于 0 吗？还是说这点 IC 只是随机噪音？

```python
from scipy import stats
ic = pd.read_pickle(base + "sig_analysis/ic.pkl").dropna()
t, p = stats.ttest_1samp(ic, 0)
print(f"t = {t:.2f}, p = {p:.3e}")
```

**本次结果**：

```
n = 868
朴素 t 检验:        t = 11.24,  p = 1.8e-27
Newey-West 修正:    t = 10.95  (滞后 5 期)
```

**为什么要 NW 修正**：IC 序列可能存在自相关，朴素 t 检验会高估显著性。qlib 的 IC 自相关很弱（见下表），所以修正后几乎没有变化。

| 滞后 | 自相关 |
|---|---|
| lag1 | +0.049 |
| lag2 | -0.032 |
| lag3 | -0.015 |
| lag4 | +0.014 |
| lag5 | +0.064 |

**结论**：`p ≈ 10⁻²⁷`，「只是随机噪音」的可能性被完全排除。这比单看 ICIR 更有说服力。

判断参考：`|t| > 2` 即 p < 0.05；日频 IC 序列通常需要 `t > 3` 才算稳妥。

#### 锚点 3：时间稳定性（分年 / 分市场状态）

这是判断「信号是否会失效」最直接的证据，比任何单个数字都重要。

```python
ic.groupby(ic.index.year).agg(["mean", "std", "count"])
```

**本次结果**：

| 年份 | IC 均值 | IC 标准差 | 天数 |
|---|---|---|---|
| 2017 | 0.0718 | 0.1145 | 244 |
| 2018 | 0.0471 | 0.1250 | 243 |
| 2019 | 0.0290 | 0.1192 | 241 |
| 2020 | 0.0333 | 0.1318 | 140 |

**两个观察**：

1. **四年全部为正**，包括 2018 熊市年 → 模型不是只拟合了单一市场环境
2. **IC 逐年衰减**（0.072 → 0.047 → 0.029 → 0.033）→ **这才是真正需要关注的问题**

衰减的可能原因：
- 因子拥挤：Alpha158 是公开因子集，用的人越多，alpha 越薄
- 市场结构变化：2017 年 A 股大盘股行情与后续年份不同
- 样本偶然性：4 年样本不足以定论，需要更长回测

**该做的下一步不是调 ICIR，而是查这个衰减趋势。**

### 三、IC 胜率：一个容易被忽略但很有用的指标

```python
print((ic > 0).mean())
```

**定义**：IC > 0 的天数占比，即「方向判对的天数比例」。

**本次 = 65.44%（568 / 868 天）**。

**为什么重要**：它能识别「靠少数极端日撑起均值」的情况。如果 IC 均值 0.05 但胜率只有 48%，说明大部分日子判错，靠少数暴涨暴跌日拉高均值——这种信号实盘极不稳定。

| IC 胜率 | 判断 |
|---|---|
| < 50% | 可疑，均值可能被极端值主导 |
| 50% ~ 55% | 勉强 |
| **55% ~ 65%** | **健康** ← 本次 65.44% |
| > 65% | 很好 |

### 四、口径对照：最容易出错的地方

同一个策略，不同口径会得出**完全相反**的结论。这张表把所有口径差异列清楚：

| 指标 | qlib 口径 | 常见业界口径 | 换算 |
|---|---|---|---|
| 年化收益 | `mean × 238`（加法累积） | `(1+r).cumprod()` 复利，252 天 | 数值不同，方向一致 |
| information_ratio | `mean/std × √238` | `mean/std × √252` | ×1.03 |
| **ICIR** | **未年化** `mean/std` | 多为**年化** `× √252` | **×15.5** |
| 最大回撤 | `(cumsum - cumsum.cummax()).min()` | 净值曲线回撤 | 加法口径略保守 |

**本次 ICIR 两种口径**：

```
未年化（qlib 打印）  0.3816
年化（×√238）        5.89
年化（×√252）        6.06
```

如果拿 0.3816 去套「ICIR > 1 是顶级因子」的标准，会误判为「极差」；拿 5.89 去套，会误判为「顶级」。**两者都是错的**——正确的做法是**和同口径的基准比**。

### 五、修正后的本次结论

| 维度 | 结论 | 依据 |
|---|---|---|
| IC 水平 | 良好（0.0468） | 落在官方 LightGBM 0.0448 与 XGBoost 0.0498 之间 |
| ICIR | **良好**（0.3816 未年化） | 高于官方 LightGBM 0.3660 |
| 统计显著性 | **极高**（t = 11.24，p = 1.8e-27） | 排除随机噪音 |
| IC 胜率 | **健康**（65.44%） | 远高于 55% 及格线 |
| 时间稳定性 | **四年全正，但逐年衰减** | 0.072 → 0.047 → 0.029 → 0.033 |
| **真正的问题** | **逐年衰减**，而非「不稳定」 | 需查因子拥挤或市场结构变化 |

**一句话**：这个信号比「ICIR 0.38 偏低」的说法**更扎实**——统计上极显著、胜率 65%、四年正 IC。真正该关注的是**逐年衰减趋势**。

## 常见误读

| 误读 | 正解 |
|---|---|
| 「IC=0.047 太低了」 | 日频 A 股 IC 能稳定到 0.03~0.05 就已是可用信号，0.1 以上反而要怀疑前视偏差 |
| 「IR=1.43，实盘年化能到 13%」 | 那是不计成本的纯选股能力，计成本后是 8.07% |
| 「年化和别的平台对不上」 | qlib 用 238 天年化 + 加法累积，与业界 252 天 + 复利不同 |
| 「pos=0 说明策略亏钱」 | pos 只统计成交价的优势占比，与盈亏无关 |
| 「ffr=1.0 说明回测完美」 | 它只说明订单全部成交，不代表收益真实；小盘股策略里 ffr 才是关键诊断 |
| 「max_drawdown 是 -37%，太危险」 | 那是 benchmark 组；策略超额回撤只有 -8.61% |
| 「ICIR=0.38 偏低，卡在有效门槛」 | 那是**未年化**口径；年化后是 5.89。qlib 官方模型里 0.38 属良好 |
| 「ICIR > 0.4 才是有效因子」 | 该门槛通常指年化 ICIR；套到未年化值上会让 qlib 26 个模型几乎全部不合格 |
| 「IC 胜率没用，看均值就够」 | 胜率能识别「均值被少数极端日撑起」；本次 65.44%，说明信号扎实 |
